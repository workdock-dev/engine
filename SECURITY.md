# Security

WorkDock is still under active development. The project is evolving quickly, and security is an important part of that process.

If you find a security issue, please let us know privately so we can understand and address it before the details become public.

## Reporting

**Please do not open a public issue for an unpatched vulnerability.**

Email **[contact@workdock.dev](mailto:contact@workdock.dev)** with:

* The affected revision or commit.
* The potential impact.
* Steps to reproduce the issue.
* A proof of concept, if available.
* Any suggested mitigation or fix.

**Do not include real credentials, secrets, or private repository data in your report.**

You should receive an acknowledgement within **seven days**. Once we understand the issue, we'll coordinate with you on the fix and, when appropriate, its disclosure.

For bugs that don't have security implications, please use the regular GitHub issue tracker instead.

## What to Expect

Because WorkDock is still evolving, security reports may require some investigation before we can determine their impact and the best way to address them.

We'll do our best to keep the reporter informed as we work through the issue. Once a vulnerability has been addressed, we'll coordinate with the reporter on when and how the details should be made public.

Thanks for helping make WorkDock safer as the project continues to evolve.
